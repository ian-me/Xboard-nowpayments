XBoard NOWPayments Plugin

A cryptocurrency payment gateway integration for XBoard.

This plugin integrates NOWPayments into XBoard, allowing users to make payments using supported cryptocurrencies.

✨ Features

* NOWPayments payment gateway integration
* Cryptocurrency payment support
* Automatic payment status updates
* IPN (Instant Payment Notification) callback handling
* Secure API communication
* Simple configuration

📋 Requirements

* XBoard
* PHP (version required by your XBoard installation)
* NOWPayments account
* NOWPayments API Key

⚙️ Configuration

1. Create an account at NOWPayments.
2. Obtain your API Key from the NOWPayments dashboard.
3. Install the plugin in your XBoard environment.
4. Configure your NOWPayments API credentials.
5. Set up the IPN callback URL if required.
